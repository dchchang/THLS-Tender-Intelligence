# Upload to GitHub

Repository:

https://github.com/dchchang/THLS-Tender-Intelligence

Recommended method:

1. Download and extract this package.
2. Open the extracted `THLS-Tender-Intelligence-Phase1` folder.
3. Test `crawler/run_crawler.bat`.
4. In GitHub, open the repository.
5. Use `Add file` / `+` → `Upload files`.
6. Drag the contents of the extracted folder into the upload area.
7. Commit the changes.

Do not upload the generated `crawler/cache` files. The `.gitignore` file excludes them when using Git locally.
